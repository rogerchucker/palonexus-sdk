# Support

Use GitHub Discussions for usage questions and GitHub Issues for reproducible
defects or feature proposals. This community project does not guarantee
response times, deployment support, architecture consulting, or operational
on-call coverage.

Questions about proprietary PaloNexus services, customer environments, account
access, or commercial support are outside this repository's support boundary.
Use the support channel supplied with that service.

Never include credentials, personal data, private configuration, or suspected
vulnerabilities in a discussion or issue. Report security concerns through
`SECURITY.md`.
